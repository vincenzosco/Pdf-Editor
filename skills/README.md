# skills/

Reusable, self-contained procedures for working on this repository.

| Skill | Use when |
|-------|----------|
| `maintain-folio/` | Adding/updating a tool, or keeping the front end and server in sync. |
| `release/` | Committing and pushing (enforces the no-ai-trailers rule). |

Each skill is a folder with a `SKILL.md`. Load it by name if your tooling
supports skills, or just read the file.
